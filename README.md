# Dylan Mugo portfolio

A single-page, game-style portfolio. Everything lives in `index.html`: markup, styles, script and the profile photo.

## Deploy

Vercel serves the repo root as a static site. `vercel.json` sets the framework to "Other", so there is no install or build step. Merging to `main` publishes to production.

## Edit

Open `index.html`. The content is in the data arrays near the top of the `<script>` block: `TICKETS` (quiz), `QUESTS` (projects), `INVENTORY` (skills) and `ACH` (certifications).
